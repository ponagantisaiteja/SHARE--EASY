# Share Easy

## About the Project
Share Easy is a document-sharing application that allows users to upload PDF files and other documents and share them through unique URLs and QR codes.

## Features
- Upload PDF and document files.
- Generate shareable links for uploaded files.
- Generate QR codes for easy access.
- Access shared documents through their links.
